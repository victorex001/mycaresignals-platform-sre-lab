# Local commands

The local environment provides scoped `start.sh`, `seed.sh`, `stop.sh`, and
`reset.sh` lifecycle commands. See
[`apps/mycaresignals/config/local/README.md`](../../apps/mycaresignals/config/local/README.md)
for start, stop, endpoint, and safety instructions.

Any future reset or seed command must remain explicitly scoped to the
`mycaresignals-local` Compose project and synthetic local data.
