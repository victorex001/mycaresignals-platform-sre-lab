# myCareSignals Therapeutic Engine — Staff

Go API and React/Vite frontend for the Staff application.

- [Local development](../config/local/README.md)
- [Repository overview](../../../README.md)
- [GitHub/AWS SRE lab delivery](../../../docs/sre/github-aws-lab.md)

GitHub Actions in the repository's `.github/workflows/` directory is the supported CI/CD system. Submit changes through a pull request to protected `main`; lab AWS operations require manual dispatch and human approval. This service's former GitLab pipeline is archived under `archive/gitlab/` at the repository root and is not active.

Use synthetic data only for development and reliability exercises. Production and demo deployment are not enabled by these lab workflows.
