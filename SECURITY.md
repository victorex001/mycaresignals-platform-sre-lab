# Security policy

This public repository contains application and infrastructure source, but it
must never contain credentials, Terraform state, real care data, production
exports, database snapshots, or load-test evidence containing sensitive data.

Report a vulnerability privately through GitHub's **Security** tab. Do not put
exploitable details, secrets, or personal information in a public issue.

The `sre-lab` environment is synthetic-only. A public repository does not make
the lab application, AWS account, Kubernetes API, database, or results bucket
public.
